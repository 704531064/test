# 试点运营手册（2周）

## 1. 目标与范围
- 人群：35~55 岁，希望提升工作与生活效率的人群。
- 规模：首批 30~50 人。
- 周期：14 天。
- 核心目标：完成首次学习闭环（登录→测评→路径学习→练习→社区互动）。

## 2. 社群 SOP

### 开营前（T-3 至 T-1）
1. 发布招募海报与报名表。
2. 完成用户分层（基础薄弱/有工具经验）。
3. 建立微信群并公告试点节奏。

### 每日节奏（D1-D14）
1. 早 8:30：发布当日学习任务（1 个微课 + 1 个练习）。
2. 晚 20:30：发布优秀作业（可匿名），引导点赞与提问。
3. 晚 21:00：汇总常见问题，沉淀到 FAQ。

### 激励机制
- 连续打卡 5 天：赠送进阶提示词模板。
- 作品墙周榜：按点赞 + 收藏综合评分。
- 结营证书：完成测评、10+ 单元学习、1 次分享。

## 3. 助教 SOP

### 值班安排
- 工作日：19:00-21:00 群内答疑。
- 每周三 20:00 直播答疑 60 分钟。

### 答疑标准动作
1. 先确认用户目标（办公/生活/行业）。
2. 让用户提供原始提示词。
3. 给出“优化版提示词 + 原因说明 + 风险提醒”。
4. 引导用户完成 1 次复盘并发布到社区。

### 风险处理
- 涉及医疗、投资、法律决策：统一提醒“仅供参考，需专业人士确认”。
- 涉及隐私泄露：先脱敏再讨论，必要时删除内容。

## 4. 内容更新节奏
- 每周新增 2 个微课单元（基于高频问题）。
- 每周更新 1 个可视化演示案例。
- 每周整理 10 条高质量问答入库。

## 5. 关键指标与阈值
- D1 留存率 > 55%
- 测评完成率 > 70%
- 社区发帖率 > 30%
- 隐私风险触发后整改率 > 85%

## 6. 复盘模板
1. 本周新增用户与活跃用户。
2. 学习路径完成情况（办公/生活）。
3. 社区互动与内容质量。
4. 典型风险案例与优化动作。
5. 下周迭代优先级。
